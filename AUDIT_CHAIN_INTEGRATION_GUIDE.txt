========================================

Files involved: audit_chain.py (new), models.py (replace — chain_hash
column added to all four *DetectorResult tables), app.py (patch — 4
small additions below).

STEP 1 — one-time helper, add near the top of app.py (after the existing
imports, before the routes):

    from audit_chain import compute_record_hash, GENESIS_HASH

    def _next_chain_hash(db, ModelClass, new_fields: dict) -> str:
        """Look up the latest chain_hash in this table and compute the
        hash the NEW row should carry. Call this once per result row,
        right before creating it, so the row is born with its chain_hash
        already set (never patched in after commit)."""
        last = db.query(ModelClass).order_by(ModelClass.id.desc()).first()
        prev_hash = last.chain_hash if (last and last.chain_hash) else GENESIS_HASH
        return compute_record_hash(prev_hash, new_fields)

identical every time: build the fields dict you were already going to
pass to the Result constructor, compute the chain hash from it BEFORE
creating the row, then include chain_hash= in the constructor.
